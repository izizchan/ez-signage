EZ Signage

NFC 電子ペーパーの札を、好きな絵や情報で書き換える道具。 Windows 版と Android 版。非公式のツールで、メーカーとは関係がない。

Android 版

APK をダウンロード

Android 8.0 以降。内蔵 NFC か、USB（OTG）接続のカードリーダーで書く。 対応リーダーは CCID 準拠のもの（ELECOM MR-ICA001BK 等）と SONY RC-S380。 リーダーは複数台つなげられる。

ストア外の配布なので、初回は「提供元不明のアプリ」の許可が要る。 2回目からはアプリの設定にある「更新を確認」から入れ替えられる。

Windows 版

Python で動く。常駐させておくと、カードを置くたびに書き込む。 ブラウザから操作する（画像の投入、版面エディタ、情報表示の設定）。 配布は準備中で、いまはソースから動かす。

できること

書き方何をするか
OneShotその場で打った文字を1枚だけ書く
サムネ選択一覧から選んだ絵をその場で書く
情報表示天気・地震・ニュース・為替・予定・ライブコメントを順に書き替える
アルバムカードを載せたまま、決めた間隔で次々に書き替える
ページカードを載せる度に、フォルダの次の絵を書く

札について

確認できているのは 4.2 インチの 4 色機（400x300 / 黒・白・黄・赤）と白黒機。 画面の更新は 4 色機で約 22 秒、白黒機で約 4 秒かかる。絵は札の色数に合わせて減色する。
