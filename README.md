# EZ Signage

NFC 電子ペーパーの札（[EZ Sign](https://www.san-technology.co.jp/)、株式会社
サンテクノロジー）を、自分の好きな絵や情報で書き換えるための道具。
Windows 版と Android 版がある。

**非公式のツール。** メーカーとは関係がない。プロトコルは
[hijimasa/EZ-Sign-nfc-unofficial-writer](https://github.com/hijimasa/EZ-Sign-nfc-unofficial-writer)
の解析結果と、公式アプリの通信ログから起こしたもの。

ここは**配布用の置き場**。ソースは別のところにある。

## 何ができるか

置いた絵をカードへ書くほか、決めた間隔で中身を作り直して書き替え続けられる。

| 書き方 | 何をするか |
|---|---|
| ページ | カードを載せる度に、フォルダの次の絵を書く |
| アルバム | カードを載せたまま、決めた間隔で次々に書き替える |
| サムネ選択 | 一覧から選んだ絵をその場で書く |
| 情報表示 | 天気・ニュース・予定・ライブコメント等を作って順に書き替える |
| OneShot | その場で打った文字を1枚だけ書く |

情報表示は、天気（気象庁）・地震・ニュース・為替・予定（Todoist）・
YouTube / Twitch のライブコメントなどを、札の解像度に合わせたドット絵にして出す。

## Android 版

[ezsignage.apk をダウンロード](ezsignage.apk)（版の情報は
[latest.json](latest.json)）

- Android 8.0 以降
- 内蔵 NFC、または USB（OTG）接続のカードリーダーで書ける
- 対応リーダー: CCID 準拠のもの（ELECOM MR-ICA001BK 等）、SONY RC-S380
- **リーダーは複数台つなげる**。使う台は設定で選べる

ストア外の配布なので、初回は「提供元不明のアプリ」の許可が要る。
2回目からはアプリの設定にある「更新を確認」から入れ替えられる。

### 入れ替えの注意

**署名が変わった版（3.81 以降）へ上げるときだけ、一度アンインストールが要る。**
それ以前の版は開発用の署名で配っていたため、そのままでは上書きできない。
以降は署名が固定なので、普通に上書きできる。

## Windows 版

Python で動く。常駐させておくと、カードを置くたびに書き込む。

- Python 3.12 以降、PC/SC 対応のリーダー（RC-S380 は nfcpy 経由）
- ブラウザから操作する（画像のアップロード、版面エディタ、情報表示の設定）
- 複数のリーダーへ同時に書ける

配布は準備中。いまはソースから動かす。

## 札について

手元で確認できているのは 4.2 インチの 4 色機（400x300 / 黒・白・黄・赤）と、
白黒機。画面の更新にかかる時間は機種で違い、4 色機は約 22 秒、白黒機は
約 4 秒（送信 0.3 秒＋更新 3.6 秒）。

絵は札の色数に合わせて減色する。素直に RGB 距離で選ぶと中間のグレーに黄が
いちばん近くなってグラデーションが汚れるので、色相で使う色を絞っている。
